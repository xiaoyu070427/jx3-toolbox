# 开心剑三助手

成就、挂件、角色信息一站式查询的 Windows 桌面工具（Python + PySide6）。

> 本软件原名「剑网三小工具」，自 v1.74 起更名为「开心剑三助手」。
> 数据仍然存放在 `%APPDATA%\JX3KeyMover\`，老用户的配置、缓存、勾选记录全部保留，无需迁移。

## 下载

最新版在本仓库的 [Releases](https://github.com/xiaoyu070427/jx3-toolbox/releases/latest) 页面，
文件名 `jx3-toolbox.exe`，单文件免安装，双击即用。
程序自身文件名不带版本号，在线更新后仍叫 `开心剑三助手.exe`，旧的那份会改名成 `开心剑三助手_v旧版本_backup.exe` 留在同目录，方便回退。

- 当前版本：**v1.96**
- 支持 Windows 10 / 11 x64，无需安装 Python
- 无 AVX-512 构建，2013 年之后的 CPU 都能直接运行

## 主要功能

- **角色信息**：名片卡展示门派、体型、装分、资历、3V3 分数、奇遇数量与游戏在线状态
  - 在线状态 / 等级走推栏官方接口，免费且不消耗令牌额度
  - 名片卡带门派纹章与门派场景背景图，无头像时自动兜底
  - 令牌与推栏 ticket 两个输入框等长，标签后的小圆点显示状态：绿=有效、红=失效、灰=没填
  - 「免费刷新」4 线程并发并分三帧上屏：0.2 秒出在线/门派，0.4 秒出装分/资历，最后补 JJC 与名片图
  - **装分 / 资历 / 3V3 不需要 JX3API 令牌**：用魔盒角色列表里的 `player_id`（7~8 位 roleId）直查推栏 badge，免费，没打过 JJC 的角色也能出
  - 门派 / 体型按返回的角色名逐条对齐，服务端返回错位时宁可留空，也不会把别人的门派套到这张卡上
- **隐元秘鉴**：成就进度按分类统计，隐藏 / 绝版成就单独计算
- **秘境挂件**：按副本列出特殊掉落与改款挂件，手勾收集
- **科举**：题库自动匹配，支持自学习
- **设置迁移**：一键打包 / 还原本机账号与插件配置，支持「正式服 / 测试服」两套客户端分别定位
- **硬件监控**：CPU / 内存 / 显卡 的温度、频率、占用与 60 秒曲线
  - 可选任务栏小条：贴着托盘左侧显示四组实时数值，鼠标穿透、不占位置
  - CPU 温度要读内核 MSR，装了 HWiNFO 或 MSI Afterburner 时自动借它们的共享内存
- **百工秘试 / 奇遇 / 帧率 / 自动弹奏 / 分享制图**

## 推栏 ticket

角色页的「推栏 ticket」是可选项，填了才能显示真实「游戏在线」。

- 仓库根目录的 `ticket.txt` 是**加密信封**（`JX3E1.` 前缀），程序内置口令，**每次启动自动拉取并解密**，也可点「更新默认 ticket」手动刷新
- 拉取多源：GitHub raw 不通时自动切 jsDelivr（国内实测 1 秒可用）
- 票据失效时界面会给出明确结论，重新取一份即可

## 自动更新清单

程序启动时会读取：

```
https://github.com/xiaoyu070427/jx3-toolbox/releases/latest/download/latest.json
```

`latest.json` 随每次发布一起上传，字段：`ver` / `url` / `size` / `sha256` / `notes`。

## 数据存放

配置与缓存都在 `%APPDATA%\JX3KeyMover\`，升级或重装程序不会丢。
